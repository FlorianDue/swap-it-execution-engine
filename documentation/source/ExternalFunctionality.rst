========================
External Functionality
========================

The SWAP-IT_Execution-Engine is a module that can be deployed in a distributed environment to execute processes on resources. However, additional modules can be attached, so that
a more complex behavior can be accomplished. Currently, there in only one such module, an order prioritization module:
